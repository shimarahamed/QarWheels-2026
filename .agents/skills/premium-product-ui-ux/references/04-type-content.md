# 04 — Typography, microcopy and content

**Use for:** content. Each rule is a context-sensitive heuristic unless a formal standard is explicitly named; do not apply mechanically.

### UX-031 · Use a type scale

- **Apply:** Define a small hierarchy of body, supporting, section, and headline styles using tokens.
- **Verify:** Heading levels and visual sizes are consistent.

### UX-032 · Write outcome-led headings

- **Apply:** State the user task or result before branding or decorative language.
- **Verify:** First-screen heading identifies the page purpose.

### UX-033 · Prefer plain language

- **Apply:** Replace jargon and ambiguous verbs with words the audience understands.
- **Verify:** Labels are clear without a glossary.

### UX-034 · Make button labels specific

- **Apply:** Name the action and likely result, such as Save changes, instead of generic Continue when avoidable.
- **Verify:** Users can predict the next step.

### UX-035 · Keep helper text persistent

- **Apply:** Place important formatting rules near the input rather than only in placeholders.
- **Verify:** Guidance remains visible after typing.

### UX-036 · Surface restrictions early

- **Apply:** State prices, limits, eligibility, and prerequisites before users invest effort.
- **Verify:** No material surprise appears at submission.

### UX-037 · Write humane errors

- **Apply:** Explain the specific issue and correction without blame, jargon, or humor at the user's expense.
- **Verify:** The error suggests a clear recovery.

### UX-038 · Use meaningful truncation

- **Apply:** Truncate only secondary text and preserve identifying information through expansion or full-label access.
- **Verify:** Users can distinguish similar items.

### UX-039 · Format values locally

- **Apply:** Use locale-aware dates, money, units, and separators; include units and time zones where material.
- **Verify:** Values are unambiguous to the target audience.

### UX-040 · Make skimming effective

- **Apply:** Use descriptive section labels, parallel lists, and front-loaded facts.
- **Verify:** A scanning reader finds the key answer quickly.
