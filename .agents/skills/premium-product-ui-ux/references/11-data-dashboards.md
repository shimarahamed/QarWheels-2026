# 11 — Dashboards, data visualization and tables

**Use for:** data. Each rule is a context-sensitive heuristic unless a formal standard is explicitly named; do not apply mechanically.

### UX-101 · Lead with decisions

- **Apply:** Show the question and decision each metric supports before choosing a chart style.
- **Verify:** Every dashboard tile has a reason to exist.

### UX-102 · Name metrics precisely

- **Apply:** Define units, periods, comparison basis, and calculation assumptions near key KPIs.
- **Verify:** Users can interpret a number without guessing.

### UX-103 · Preserve accurate scales

- **Apply:** Use appropriate axes and avoid misleading truncation, especially for bars and comparisons.
- **Verify:** Values cannot be visually overstated.

### UX-104 · Provide context for deltas

- **Apply:** Show baseline, percentage versus absolute change, and the comparison period.
- **Verify:** A positive or negative change has interpretable meaning.

### UX-105 · Use suitable chart forms

- **Apply:** Pick bars for discrete comparison, lines for trends, and tables for exact lookup rather than novel ornament.
- **Verify:** Intended insight is easy to extract.

### UX-106 · Represent missing data

- **Apply:** Distinguish zero, not available, pending, suppressed, and not applicable.
- **Verify:** The viewer cannot confuse absent data with actual zero.

### UX-107 · Offer data table alternatives

- **Apply:** Provide textual or tabular access to chart content for keyboard, screen reader, and precision use.
- **Verify:** No key insight depends only on graphics.

### UX-108 · Make filters transparent

- **Apply:** Display applied time range, segments, data freshness, and any inherited filters.
- **Verify:** Export and visible values use the same scope.

### UX-109 · Design dense tables deliberately

- **Apply:** Keep headers clear, preserve sorting meaning, and make row actions discoverable on small screens.
- **Verify:** Users can compare values and act without losing row context.

### UX-110 · Use restrained numeric motion

- **Apply:** Animate values only when meaningfully updated and avoid decorative rolling for volatile live financial figures.
- **Verify:** Motion cannot imply false precision or completion.
