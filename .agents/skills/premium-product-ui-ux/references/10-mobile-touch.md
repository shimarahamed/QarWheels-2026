# 10 — Mobile, touch and gesture design

**Use for:** mobile. Each rule is a context-sensitive heuristic unless a formal standard is explicitly named; do not apply mechanically.

### UX-091 · Prioritize thumb reach

- **Apply:** Keep frequent primary controls reasonably reachable and avoid edge conflicts with system gestures.
- **Verify:** One-handed core tasks remain comfortable.

### UX-092 · Use visible affordances

- **Apply:** Make interactive surfaces look actionable rather than depending on hidden swipe knowledge.
- **Verify:** First-time users discover the primary operation.

### UX-093 · Pair gestures with controls

- **Apply:** Offer visible buttons or menus for swipe, long-press, and drag operations.
- **Verify:** Every important action has a discoverable alternative.

### UX-094 · Handle virtual keyboard

- **Apply:** Keep focused inputs, validation messages, and submit actions visible above the software keyboard.
- **Verify:** Forms remain usable while typing.

### UX-095 · Prevent accidental taps

- **Apply:** Space adjacent destructive and routine actions and avoid tiny low-separation targets.
- **Verify:** Typical touch errors are recoverable.

### UX-096 · Respect platform conventions

- **Apply:** Follow native back, navigation bars, sheets, and system UI patterns when they fit the app.
- **Verify:** The interface behaves as users expect on each platform.

### UX-097 · Use progressive disclosure

- **Apply:** Collapse supporting detail while retaining key information and accessible paths on narrow screens.
- **Verify:** Main task never depends on desktop-only content.

### UX-098 · Design offline transitions

- **Apply:** Explain loss of connectivity and distinguish locally queued work from server-saved work.
- **Verify:** Users know if action is really completed.

### UX-099 · Manage orientation changes

- **Apply:** Reflow rather than resetting forms, search context, scroll, or selection.
- **Verify:** Device rotation does not destroy progress.

### UX-100 · Test real-device feel

- **Apply:** Check scroll, touch latency, haptics when supported, gesture competition, and on-screen keyboard on devices.
- **Verify:** Performance is not judged solely by desktop emulation.
