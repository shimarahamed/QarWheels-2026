QARWHEEL — SHARED HOSTING DEPLOYMENT

1. Extract the ZIP on your computer.
2. Open the extracted folder. Upload EVERYTHING INSIDE the folder into your website public_html/ folder (or the selected domain document root). Upload index.html, .htaccess, assets/, ar/, and all page folders at the same level.
3. If the file manager hides .htaccess, enable "Show Hidden Files". The website works without PHP, Node.js, npm or a build process.
4. Visit https://qarwheel.qa/ and confirm CSS, menus, pages and Arabic language toggle.
5. If replacing an old site, remove or back up old index files and stale assets to prevent conflicts.
